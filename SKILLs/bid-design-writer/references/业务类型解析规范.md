# 业务类型解析规范

> 配套 SKILL.md 阶段一「业务类型识别」使用。定义建筑、勘察、检测加固、全过程咨询、工程施工、监理/造价/EPC 等业务类型及综合标的识别特征、技术要求提取维度、成果要求差异与常见误区。
> 使用方式：识别出业务类型后，按对应章节的「提取维度」执行提取；内置维度未覆盖的类型按「7. 其他工程类型通用维度」提取，不得跨类型套用或默认按建筑设计处理。本规范适用于**所有建筑行业工程招标文件**的解析。

---

## 0. 识别流程总览

```
招标文件 → ① 关键词识别 → ② 评分项佐证 → ③ 成果要求佐证 → ④ 多业务判定 → 输出业务类型
```

| 业务类型 | 识别关键词（标题/招标公告/服务范围） | 评分项常见名称 | 成果常见名称 |
|---------|--------------------------------------|---------------|-------------|
| 建筑工程设计 | 设计、方案、施工图、初步设计、建筑方案、深化设计、概念设计 | 设计方案、设计质量、设计深度、专业配合 | 设计方案文本、设计说明、图纸、效果图 |
| 岩土工程勘察 | 勘察、钻探、勘探、岩土、原位测试、勘察纲要、详勘/初勘/补勘 | 勘察方案、勘察纲要、技术措施、勘察进度 | 勘察报告、勘探点平面图、钻孔柱状图、剖面图、土工试验成果 |
| 检测加固 | 检测、鉴定、加固、可靠性、抗震鉴定、回弹、钻芯、碳纤维、粘钢、增大截面 | 检测方案、鉴定方案、加固设计、检测手段、抽样方案 | 检测方案、检测报告、鉴定报告、加固设计方案、加固施工方案 |
| 全过程工程咨询 | 全过程、项目管理、造价咨询、监理、招标代理、统筹管理、工程咨询 | 实施方案、组织架构、统筹管理、投资控制、咨询成果 | 咨询实施方案、项目管理规划、各专项报告、台账、月报 |
| 工程施工 | 施工、桩基、土建、市政、安装、施工作业、施工组织设计 | 施工组织设计、施工方案、进度计划、质量安全措施、资源配置 | 施工组织设计、施工方案、进度网络图、设备/劳动力表 |
| 工程监理/造价/EPC 等 | 监理、施工监理、旁站、造价、清单、结算审核、EPC、总承包、交钥匙 | 监理大纲、监理规划、造价控制、总承包实施方案 | 监理规划、监理细则、造价成果文件、总承包实施方案 |
| 综合标 | 含两类以上业务关键词（如勘察设计、检测加固、设计施工一体化） | 混合（按主业务口径） | 按所含业务分别列示 |

> 识别冲突时以「成果要求 + 评分项」双重佐证为准；仍无法判断时询问用户，并按用户口述类型提取且标注「业务类型为用户确认」。

## 1. 建筑工程设计

### 1.1 适用范围
方案设计、初步设计、施工图设计、方案深化、专项设计（幕墙/景观/室内/智能化等）等技术标。

### 1.2 技术要求提取维度（阶段一 2.1 展开项）

| 维度 | 提取要点 | 示例/说明 |
|------|----------|-----------|
| 设计范围与工作内容 | 各阶段工作边界、设计一体化要求 | 方案+初设+施工图全流程 / 仅方案阶段 |
| 设计深度要求 | 阶段对应深度 | 方案报规深度、施工图出图深度 |
| 专业范围 | 建筑/结构/机电/暖通/给排水/智能化等 | 未列专业不得补造 |
| 关键技术指标 | 容积率、建筑高度、退线、车位、面积指标 | 须有 A 级出处 |
| 设计依据 | 规范、标准、政策文件清单 | 名称+编号+年份核对有效性 |
| 成果清单 | 文本、图纸、模型、BIM 等 | 逐项提取，未提及标「未提及」 |
| 约束/禁止项 | 强制性要求、红线、暗标要求 | 影响合规底线 |
| 设计意向 | 形象、风格、材料、空间意向（如有） | 未明确不得虚构 |

### 1.3 成果要求差异
- 方案阶段：设计说明、效果图、总平面、平立剖、分析图、经济技术指标表、报规文件
- 施工图阶段：各专业施工图、设计总说明、计算书、图纸目录、材料表
- 专项：专项设计说明与图纸（BIM 模型及漫游、绿色建筑专项、海绵城市专项等）

### 1.4 常见误区
- 把效果图/透视图当必交成果——必须招标文件明确要求才输出
- 按模板硬套章节结构——以评分项和目录要求为准
- 图纸需求按图名惯例推断——只提取招标文件明确列出的图名

## 2. 岩土工程勘察

### 2.1 适用范围
房屋建筑与市政工程的可行性研究勘察、初步勘察、详细勘察、施工勘察（补充勘察），以及勘察设计一体化项目中的勘察部分。

### 2.2 技术要求提取维度（阶段一 2.2 展开项）

| 维度 | 提取要点 | 示例/说明 |
|------|----------|-----------|
| 勘察阶段 | 初勘/详勘/施工勘察/专项勘察 | 阶段决定工作量与深度 |
| 勘探点布置 | 孔位、孔距、孔深、数量、控制孔比例 | 详勘一般性勘探点间距 15-30m，控制性勘探点占比约 1/3-1/2（以招标文件为准） |
| 勘察手段 | 钻探、静力触探、动力触探、标准贯入、波速测试、原位测试、取样、室内试验 | 手段组合影响工作量与设备配置 |
| 技术指标要求 | 岩土分层、承载力特征值、压缩性指标、抗剪强度、地下水、液化判别、不良地质作用、特殊性岩土 | 逐项列出招标要求的报告内容 |
| 执行规范 | GB 50021、GB 50007 及各地方规程 | 以招标文件列明为准，核对编号与年份 |
| 外业作业要求 | 安全文明施工、泥浆处理、岩芯保存、环保、季节措施 | 常作为评分项（安全文明施工） |
| 成果要求 | 勘察报告、图表、试验成果、电子文件 | 按《建筑工程勘察文件编制深度规定》等核对构成 |
| 接口要求 | 勘察设计一体化时需提交的设计参数与地基处理建议 | 与后续设计阶段的接口内容 |

### 2.3 成果要求差异
- 文字报告：工程概况、勘察目的与任务、场地工程地质条件、岩土参数分析与建议、结论与建议
- 图表：勘探点平面布置图、工程地质剖面图、钻孔柱状图、原位测试成果图表、土工试验成果汇总表、物理力学指标统计表、水质分析成果
- 附件：勘察纲要（投标阶段）、岩芯照片、电子文件（CAD/PDF）

### 2.4 常见误区
- 把「勘察方案（投标）」写成「勘察报告（成果）」——投标阶段交付的是勘察纲要/技术方案
- 勘探工作量凭经验自定——必须按招标文件的布孔要求提取
- 承载力等参数直接给出数值——未确认的岩土参数必须标「待确认」或说明取值依据
- 忽略外业安全文明施工要求——常是独立评分项

## 3. 检测加固

### 3.1 适用范围
既有建筑结构检测鉴定、加固设计、加固施工，及检测加固一体化项目。注意区分三种投标内容：
- 检测鉴定标：交付检测方案 → 检测报告（含鉴定结论）
- 加固设计标：交付加固设计方案（计算书+图纸）
- 加固施工标：交付加固施工方案（工艺+组织+质量安全）
- 一体化标：检测+鉴定+加固设计（+施工）全链条

### 3.2 技术要求提取维度（阶段一 2.3 展开项）

| 维度 | 提取要点 | 示例/说明 |
|------|----------|-----------|
| 检测范围 | 结构类型、检测对象（梁板柱墙/地基基础）、部位 | 明确检测覆盖范围 |
| 检测手段 | 回弹、钻芯、超声、钢筋扫描、裂缝观测、荷载试验、砌体/砂浆强度检测、沉降观测 | 手段必须与标准对应 |
| 抽样规则 | 抽样比例、构件数量、代表部位、检测批量 | 按 GB/T 50344 等标准核对；未明确标「待确认」 |
| 检测依据 | GB/T 50344、GB/T 50784、JGJ/T 23、JGJ/T 152 等 | 以招标文件列明为准 |
| 鉴定评级要求 | 安全性/可靠性/抗震鉴定、评级标准（Asu/Bsu 等） | 依据 GB 50292、GB 50023 等 |
| 加固设计范围 | 加固对象、加固方法（增大截面/外包型钢/粘钢/碳纤维/植筋/置换）与选用原则 | 方法选择须有计算依据 |
| 加固施工要求 | 工艺流程、材料要求、施工质量控制、验收标准 | 涉及施工内容时提取 |
| 成果要求 | 检测方案、检测报告、加固设计方案、加固施工方案 | 按投标内容类型提取对应成果 |

### 3.3 成果要求差异
- 检测鉴定标：检测方案（投标）→ 检测报告（履约）：检测数据汇总、构件评级、结论与建议
- 加固设计标：加固设计说明书、计算书、加固构造详图、材料表
- 加固施工标：施工组织设计、工艺流程、质量控制与验收措施、安全文明施工方案
- 一体化标：按上述组合，注意阶段衔接与接口描述

### 3.4 常见误区
- 混淆「检测」与「鉴定」——检测是数据获取，鉴定是基于数据的评级，结论表述必须区分
- 抽样比例自行确定——必须引用标准条文或招标要求，未明确标「待确认」
- 检测手段罗列但无依据——每项手段须有对应标准与方法说明
- 加固方法选择无计算/规范支撑——写清依据 GB 50367 等的选用原则

## 4. 全过程工程咨询

### 4.1 适用范围
全过程工程咨询服务，含项目管理、投资决策咨询、设计管理、造价咨询、工程监理、招标代理、BIM 咨询等模块的组合；政策依据含发改投资规〔2019〕515 号等（以招标文件要求为准）。

### 4.2 技术要求提取维度（阶段一 2.4 展开项）

| 维度 | 提取要点 | 示例/说明 |
|------|----------|-----------|
| 咨询服务模块 | 各模块组合与范围边界 | 项目管理+造价+监理 / 全模块 |
| 服务阶段覆盖 | 决策/实施/竣工各阶段 | 明确阶段范围与介入时点 |
| 组织架构与人员 | 项目总负责人、各专业咨询工程师、驻场要求、资格 | 人员配置须响应资质要求 |
| 控制目标 | 投资/质量/进度/安全/合同/信息管理目标 | 目标值须与招标一致 |
| 协调管理机制 | 与建设方、设计、施工、监理的接口与例会制度 | 写清机制而非口号 |
| 成果体系 | 各阶段报告、台账、月报、专项报告、管理文件 | 按招标要求逐项提取 |
| 数字化要求 | BIM 平台、项目管理信息系统、智慧工地 | 有则提取平台与功能要求 |

### 4.3 成果要求差异
- 投标阶段：全过程咨询实施方案、组织架构图、人员配置表、各模块咨询方案
- 履约阶段：项目管理规划、各专项报告（可研/评估/造价/监理）、台账（合同/进度/变更/支付）、月报周报、会议纪要、总结报告
- 注意：投标交付的是「实施方案」，不是履约期的各类成果

### 4.4 常见误区
- 把咨询实施方案写成监理方案——监理只是其中一个模块
- 模块罗列而缺少统筹机制——全过程咨询的核心是各模块的协同与统筹
- 组织架构与人员配置脱节——人员表须能对应到组织架构与资质要求
- 控制目标与招标文件不一致——目标值必须提取自招标文件

## 5. 综合标（多业务合并）

### 5.1 判定
同一招标文件含两类以上业务（如勘察设计一体化、检测加固一体化、设计施工总承包、设计+全过程咨询）即判定为综合标。

### 5.2 处理规则
1. **主业务确定**：评分权重最高、篇幅最大的业务为主业务；其余为伴随业务。
2. **提取组织**：主业务按对应类型全量提取（2.x 对应维度）；伴随业务只提取服务范围、阶段深度、成果要求与评分边界。
3. **接口与统筹**：单独提取各业务之间的接口要求与统筹协调机制（如勘察成果向设计传递的参数、检测结论对加固设计的输入）。
4. **评分处理**：评分表整体提取；主业务评分项全量展开得分要点，伴随业务评分项列名称、分值并标注「联合体/外部专业负责」。
5. **责任边界**：不属于投标联合体能力的业务内容标注「待用户确认」，不生成正文与承诺。

### 5.3 常见误区
- 按单个业务类型套用提取，遗漏伴随业务——必须逐一识别所含业务
- 主业务与伴随业务篇幅失衡——按评分权重分配
- 忽略业务间接口——接口与统筹常是综合标的高分值评分点

## 6. 工程施工

### 6.1 适用范围
房建/市政/工业项目的桩基、土建、市政、安装等施工标，交付施工组织设计技术标。

### 6.2 技术要求提取维度（阶段一 2.5 展开项）

| 维度 | 提取要点 | 示例/说明 |
|------|----------|-----------|
| 工程范围与工作内容 | 分部分项工程清单 | 桩基/土建/安装/市政各分部 |
| 工程类型与规模 | 结构形式、工程数量、主要工程量 | 灌注桩 9933 根、桩径 800/600 |
| 施工方法与工艺 | 关键工序、专项方案 | 冬雨季施工、大风天气、深基坑、泥浆护壁 |
| 施工部署与组织 | 施工顺序、流水段、施工平面布置 | 分区段施工组织 |
| 进度计划要求 | 里程碑、控制点、网络图/横道图、计划深度 | P6 三级进度计划、WBS 六级 |
| 资源配置要求 | 施工设备、试验检测仪器、劳动力 | 自有设备数量、劳动力动态曲线 |
| 质量/安全/环保体系 | 质量目标、专职安全员配置、应急预案 | 100% 合格、安全员 1/50 人 |
| 执行规范与标准 | 施工及验收规范清单 | JGJ 94、GB 50202、GB 50300 等 |
| 成果要求 | 施工组织设计文本+附表 | 设备表/劳动力表/进度网络图/总平面图/临时用地表 |

### 6.3 成果要求差异
- 投标阶段：施工组织设计（施工部署、进度计划、资源配置、施工方法、质量安全环保体系、管控难点分析）+ 附表（主要施工设备表、试验检测仪器表、劳动力计划表、开竣工与进度网络图、施工总平面图、临时用地表）+ 关键技术响应表
- 履约阶段：专项施工方案、施工记录、检验批资料、交工资料

### 6.4 常见误区
- 把施工组织设计写成通用范本——必须结合本工程特点与评分点针对性编写
- 进度计划只给横道图——评分常要求三级计划、关键路径与纠偏闭环
- 设备/人员配置无证据——自有设备类评分常要求购置发票等证明材料
- 忽略专项方案评分点——大风/冬季/雨季等专项方案常是独立评分项

## 7. 其他工程类型（监理/造价/EPC/项目管理等）

### 7.1 适用范围
工程监理、造价咨询、招标代理、项目管理、EPC 总承包等未内置专用章节的建筑行业工程类型。

### 7.2 技术要求提取维度（阶段一 2.6 展开项）

| 维度 | 提取要点 | 示例/说明 |
|------|----------|-----------|
| 工程/服务范围 | 模块组合与工作清单 | 监理（三控三管一协调）、造价（全过程/结算审核）、EPC（设计采购施工一体化） |
| 阶段覆盖 | 决策/实施/竣工各阶段 | 明确阶段范围与介入时点 |
| 组织与人员 | 负责人资格、专业人员、驻场要求 | 总监注册监理工程师、造价师、EPC 项目经理 |
| 控制目标 | 质量/进度/投资/安全/合同/信息 | 目标值须与招标一致 |
| 执行规范与标准 | 对应行业规范 | 监理规范 GB/T 50319、工程量清单计价规范 GB 50500 等 |
| 成果要求 | 方案/报告/台账/月报/图纸/清单 | 按招标要求逐项提取 |
| 协调与接口 | 与业主/设计/施工/监理接口 | 例会制度、报审流程 |
| 约束与禁止项 | 红线要求 | 影响合规底线 |

### 7.3 常见误区
- 按设计/勘察维度套用提取——监理、造价、EPC 的技术重心完全不同
- 只列模块不写机制——统筹/接口机制常是高分值评分点
- 控制目标与招标不一致——目标值必须提取自招标文件

---

## 8. 跨业务通用提取要点

1. **资质/人员/业绩**：所有业务类型均须提取投标人资质等级、项目负责人资格、类似业绩要求，作为商务与人员响应章节的依据。
2. **暗标/废标**：所有类型共用同一套暗标与废标条款提取，不因业务类型而异。
3. **承诺性要求**：响应时限、到场时限、人员稳定性、服务频次等承诺事项，各类型均须提取并列入招标约束模型「承诺性约束」，作为阶段二编写承诺章节的依据。
4. **规范核对**：各业务的规范引用均须核对名称、编号、年份、适用性；过期、跨地区或不适用规范不得复用。
