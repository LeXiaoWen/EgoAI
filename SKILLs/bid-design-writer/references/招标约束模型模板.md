# 招标约束模型模板

> 配套 SKILL.md 阶段一使用。四类信息提取完成后，必须按本模板将结果固化为「招标约束模型」；该模型是阶段二技术标书编写的**唯一输入依据**。
> 适用范围：建筑工程设计、岩土工程勘察、检测加固、全过程工程咨询及综合标。

## 一、使用规则

1. **来源必注**：每个字段必须注明来源（文件名 + 章节号或页码）；无法定位来源的值不得写入模型。
2. **缺失即标**：招标文件未提及的字段一律标注「**未提及**」；未确认的标注「**待确认**」，不得用业务惯例、历史项目或经验值补足。
3. **A 级优先**：招标文件、澄清/补遗、正式规划条件为 A 级来源；B/C 级参考材料须通过实体污染与数值来源审计后方可进入「已确认项目事实」。
4. **冲突处理**：A 级与 B/C 级冲突时，模型只保留 A 级值；冲突字段写入「风险与待确认事项」。
5. **唯一依据**：阶段二编写的章节、数值、措施、承诺、图件和文件，全部必须能回链至本模型的对应约束项；无回链依据的内容一律不生成。

## 三、约束模型 → 编写影响映射（内部使用）

| 约束类别 | 直接影响 |
|----------|----------|
| 业务类型 | 技术内容维度、成果形态、专业分工 |
| 服务范围/专业范围 | 章节编写边界、外部责任标注 |
| 阶段/深度 | 正文技术深度、成果颗粒度 |
| 评分项与分值 | 章节结构、篇幅分配、证据优先级 |
| 废标/暗标 | 合规底线、去标识化处理 |
| 制作格式 | 排版、装订、文件格式 |
| 已确认项目事实 | 正文唯一事实池（A/B 级） |
| 承诺性要求 | 承诺表述的具体数值与时限 |

## 四、完整性检查（生成约束模型后逐项确认）

- [ ] 业务类型已识别并注明依据（综合标注明主业务+伴随业务）？
- [ ] 四类信息（项目/技术/评分/制作）是否全部覆盖？
- [ ] 每个字段是否标注来源（文件名+章节/页码）？
- [ ] 缺失字段是否标「未提及」，未确认字段是否标「待确认」？
- [ ] 评分表是否完整无遗漏，废标条款是否逐条列出？
- [ ] 暗标要求是否明确（有/无+具体要求）？
- [ ] 非本业务评分项是否只标注责任边界、未展开？
- [ ] 承诺性约束（时限/人员/频次/目标）是否逐项提取？
- [ ] 已确认项目事实是否均为 A/B 级来源，无未确认数值混入？
- [ ] 阶段二可回链性：模型字段是否足以支撑正文每个章节/数值/图件/承诺？
